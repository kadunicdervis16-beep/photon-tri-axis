## Methodology & The Standard of Evaluation

When a new gravity framework is proposed, the theoretical physics community often assumes an impossible, unspoken metric: that a newcomer must derive everything from first principles, contain zero free parameters, and predict all observations without adjustment. 

Yet, an honest survey of twenty-seven published gravity Lagrangians—from Einstein-Hilbert to Horndeski to Loop Quantum Gravity—reveals that no existing framework meets this standard. Every successful model in history shares an identical structural loop: **adopt an input structure, derive the programmatic consequences, and match data to observation**. General Relativity adopted an elegant functional form and covariance choices; MOND adopted a specific acceleration scale fitted directly to galactic rotation curves.

The standard of evaluation in theoretical physics is not *zero adoption*, but **transparent adoption**. 

The **Photon Tri-Axis Framework** operates with absolute methodological transparency. It eliminates fine-tuned, fitted constants entirely. Instead, it adopts a minimal, explicit geometric architecture and derives all mass, gravity, time, and kinematic velocities as precise spatial departures from a single, universal reference state:

* **The Photon Baseline:** The absolute universal reference state for all geometric accounting.
* **The Closure Principle:** The fundamental geometric metric governing configuration stability. Loops must close cleanly, or they undergo decay until reconciliation is reached.
* **The Kinematic Gap Axiom:** No physical configuration can rest at absolute zero velocity ($v = 0$) or reach light speed ($v = c$) without immediately losing its structural configuration.

This repository serves as the centralized master ledger, code registry, and analytical framework tracking these structural departures across the entire multi-paper series.
